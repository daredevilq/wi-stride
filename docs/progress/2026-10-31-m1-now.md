# M1 – Live connection diagnostics, "Now" screen (2026-10-31)

The first real feature: the **Now** tab shows the current Wi-Fi connection live, without a refresh button.

## Done
- **Now screen** – SSID, BSSID, RSSI with a signal-quality label and a live 60 s RSSI chart; frequency, band, channel, channel width, Wi-Fi standard, link speeds, security; IPv4/IPv6, gateway, DNS, prefix, MTU. Long press copies a value.
- **State cards with actions** – Wi-Fi off, airplane mode, not connected, missing permission, location off – each with a button to the right system panel or permission request.
- **Honest "unavailable" values** – a field the device or Android version does not report is shown as unavailable with a reason, never as a fake zero.
- **`domain:wifi`** – pure Kotlin logic: frequency → band/channel (2.4 / 5 / 6 GHz), channel width, dBm → quality, Wi-Fi standard and security mapping.
- **`core:wifi`** – Android sources wrapped in Flows: Wi-Fi/airplane/location state, network callback with link properties (per API level, polling on Android 10–11), scan results for the channel width. Works only while the screen is visible.
- **Tests** – 114 unit/UI tests in total (Robolectric for Android sources and screen states).

## Works
- Checked on a Samsung Galaxy A53 (Android 16): values match the system Wi-Fi status; toggling Wi-Fi, airplane mode, location and the permission shows the right card; rotation keeps the screen; no crashes; listeners are released after leaving the tab.
