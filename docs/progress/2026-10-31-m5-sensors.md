# M5 (part 1) – Motion sensors and trace recorder (2026-10-31)

Groundwork for the indoor mapper: reading the motion sensors that Pedestrian Dead Reckoning will use, and a tool to record real walks for tuning it. Nothing new is visible in the regular app yet.

## Done
- **`core:sensors`** – Flow-based sources for the accelerometer, game rotation vector / rotation vector (heading) and the step detector, ~50 Hz with batching, processed off the main thread; a check of which sensors the device has.
- **Trace recorder (debug builds only)** – a separate *WiStride Trace* launcher entry that records a walk to CSV (timestamp, acceleration, orientation quaternion, steps) plus a metadata file. These recordings will become test fixtures for step detection and heading.
- The step-detector permission (`ACTIVITY_RECOGNITION`) is declared only in debug builds.

## Works
- Checked on a Samsung Galaxy A53 (Android 16): a ~22 s walk recorded at ~50 Hz; sensors are registered only while recording and released after Stop or leaving the screen; the file is saved and can be pulled with `adb pull`.
